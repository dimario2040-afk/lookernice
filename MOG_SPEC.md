# MOG — Telegram Mini App (спека v0, заморожена)

> Казуал-гача 18+ на Telegram. Юзер кидает фото → получает **карточку с МОГ-баллами**
> (цифра + тир), крутит **рероллы ±0.3**, вызывает **одного человека** на батл по тегу.
> **Любая** аналитика внешности (и в боте, и в мини-аппе) сопровождается МОГ-баллами
> и дисклеймером **очень мелким шрифтом**.

---

## 1. Архитектура

- **Один процесс.** В webhook-режиме (`RENDER_EXTERNAL_URL` или `PUBLIC_URL` задан) aiohttp-приложение
  из `bot.py` обслуживает всё:
  - `POST /webhook/<secret>` — aiogram (апдейты)
  - `GET /` — health (`ok`)
  - `GET /app` и `GET /app/` — Telegram Mini App (`webapp/index.html` + статика `/app/static/*`)
  - `/api/*` — JSON API игры
- **Локально (polling)** — только бот. API/мини-апп не поднимается (для рероллов и батлов нужен
  публичный HTTPS → Render или ngrok).
- **Хранилище:** SQLite через `aiosqlite`, файл `mog.db` (создаётся сам). 
- **Фото НЕ хранится:** считаем `hash` от байтов и забываем. Приватность + минус биометрический риск.
- **Push результатов батлов в чат:** `_pending_battles` в БД + отправка через `bot` (aiogram) из API-хендлера.

## 2. Файлы

```

game/api.py         # aiohttp routes /api/* + сборка статики мини-аппа; register_webapp(app, dp, bot, ...)
webapp/index.html
webapp/app.js
webapp/style.css
```

## 3. Ролл (`game/rolls.py`)

- `base` (2.0–4.4): **детерминированно** из `sha256(photo_bytes)` → для одной фотки всегда одна база
  (чтобы «переизготовка» давала ±0.3 вокруг неё, а не прыгала по всему диапазону).
- `noise`: `random.gauss(0, 0.18)` → ~90% попадает в ±0.3.
- **КРИТ** (2%): `+uniform(0.5, 0.8)` → `rarity="Mythic"`.
- **ПРОВАЛ** (3%): `−0.5` → комичный флаг. Крит и провал взаимоисключающие.
- `score = clamp(base + noise + bonus, 1.0, 5.0)`, округление до 2 знаков.
- **Тир/редкость** по `score`: `<2.5` Common · `2.5–3.19` Rare · `3.2–3.9` Epic · `≥3.91` Legendary · крит → Mythic.
- **Статы** (для баров карты): `jaw, eyes, cheeks, harmony, groom, aura` — из `base` × профиль + мелкий
  детерминированный джиттер от хэша. Каждый 0–100.
- `roast`: жёсткая харш-строка из **банка по тиру** (18+, дерзко, «свой пацан с форума»). 
  **НЕ** призывы к самоповреждению/суициду и не оскорбления по защищённым признакам.
- `disclaimer`: строка мелким шрифтом (см. §7).

## 4. API (JSON; авторизация — заголовок `X-Init-Data` = `Telegram.WebApp.initData`)

Все `/api/*` (кроме `/api/health`) требуют валидный `initData`. Парсится на сервере, `user_id` берём
**только** оттуда (никогда не из тела запроса).

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| GET | `/api/me` | — | `{ user:{id,first_name,username}, rolls_left, rolls_total, best_roll\|null, history:[...] }` |
| POST | `/api/photo` | `{ photo_b64 }` | `{ photo_token }` — байты в память, TTL ~15 мин, на диск НЕ пишем |
| POST | `/api/roll` | `{ photo_token }` | `{ roll_id, score, tier, rarity, crit, failed, stats{}, roast, disclaimer, rolls_left }` |
| GET | `/api/leaderboard?scope=global` | — | `[ { rank, name, score, tier, ts } ]` |
| GET | `/api/battle/{id}` | — | `{ status, challenger:{...}, opponent:{...}, winner_id\|null }` |
| POST | `/api/battle/{id}/photo` | `{ photo_token }` | оппонент кидает фото → ролл → resolve → `{ winner_id, result }` |

Ошибки: `401` (нет/битый initData), `402` (лимит роллов исчерпан, `{"error":"no_rolls"}`), `400/404/409`.

## 5. Бот (`bot.py`)

- `setChatMenuButton` → WebApp `{url}/app`. В `/start` — кнопка `🎰 Открыть MOG`.
- **Батл по тегу (главное):** в группе `/mog @username` **или** ответ на сообщение + `/mog`:
  - создать батл (challenger = отправитель, opponent = упомянутый),
  - пост в чат: `⚔️ {challenger} вызывает {opponent} на мог-батл` + **WebApp-кнопка** `Принять бой`
    (`web_app` url `{url}/app?battle={id}` или `startapp=battle_{id}`),
  - оппонент открывает → кидает фото → resolve → бот постит в чат жёсткий результат (тегает обоих, кто кого смог).
- **Обычная аналитика фото (текущий `on_photo`):** к разбору **добавлять МОГ-баллы** + мелкий дисклеймер (§7).
- `bot` и `dp` должны быть доступны из API-хендлеров для пуша в чат.

## 6. Mini App UX (`webapp/`)

Экраны: **Home** (кнопка «Кинуть фото / Крутить») → **Loading** → **Roll-анимация** (слот-машина,
цифра набегает) → **Карта** (арт-аватар-плейсхолдер, ник, тир-рамка с свечением по редкости,
бары статов, бейдж `ролл X.XX · критов N · роллов M`, roast) → кнопки **«Крутить ещё»**,
**«Поделиться»** (canvas → PNG), **«В батл»**. Отдельный экран **Battle** и **Leaderboard**.
- Мобильный first, тёмная тема, 18+ дерзкий вид, хаптики `Telegram.WebApp.HapticFeedback`.
- Фото: `<input type=file accept="image/*" capture>` → base64 → `/api/photo` → `/api/roll`.
- `start_param` (`battle_<id>`) → открыть экран батла и предложить кинуть фото.
- Вне Telegram (нет `initData`) — деградировать: показать заглушку/демо, не падать.
- Дисклеймер — **реально мелким шрифтом** внизу карты.

## 7. MOG-баллы + дисклеймер (везде)

Любая выдача анализа внешности сопровождается строкой вида:
`🎲 МОГ: 3.42 · Epic` и мелким шрифтом:
> MOG — развлекательная игра. Балл генерируется случайно, не является научной, медицинской
> или объективной оценкой внешности.

## 8. Зависимости

- Добавить `aiosqlite>=0.20` в `requirements.txt` и `requirements-render.txt`.

## 9. МОНЕТИЗАЦИЯ (Telegram Stars) — «поднять бабла»

Принципы: **ядро бесплатное и смешное**, платят за **удачу**, **понты** и **скорость**.
Всё через Stars (инвойсы форвардятся в любой чат, ~$0.013/⭐ при выводе, холд 21 день).

| Товар | Цена ⭐ | Роль |
|---|---|---|
| Стартовый паблик (разовый) | 99 | Лучшая конверсия. 25 роллов + рамка + крит-токен |
| Пак роллов «Reroll x5» | 25 | Импульс |
| Пак роллов «Reroll x25» | 99 | Основной оборот |
| Пак роллов «Reroll x100» | 299 | Киты |
| **Крит-токен** (гарант +0.5) | 49 | «Пити»-система, покупают на границе тира |
| Рамки/скины карты | 30–150 | Косметика (Marvel-Snap-лестница) |
| **Holo/Aura-эффект** | 199 | Дорогой тир: меняет ПОВЕДЕНИЕ карты (анимация, фольга) |
| Сезон-пасс (мес) | 249 | Ретеншен + косметика + роллы |
| **Гифт другу** (роллы/рамка/звезда) | любой | Соц. механика → виральность + оборот |
| «Второй шанс» после провала | 15 | Докупить ролл сразу после неудачи (точка макс. боли) |
| «Пин в топ чата» (24ч) | 99 | Понот-флекс в лидерборде |

+ **Rewarded ads**: +1 ролл за просмотр (Telegram Ads) — вход без Stars + монетизация.
+ **Лимитированные серийные карты**: «Карта #1 в мире», сезонные нумера.

Правила: показывать **шансы** (2%/3%/95%), без «казино-петли» за реальные деньги сверх роллов, без лутбоксов
за фиат. 18+ снимает часть ограничений, но прозрачность — и для репутации, и против сторов.

## 10. ВИРАЛЬНОСТЬ («любые вирусные истории»)

Ядро роста — **публичная боль** (юзер сам этого хочет). Каждая петля даёт и вовлечение, и повод заплатить.

| Петля | Механика | Триггер монетизации |
|---|---|---|
| **«🔍 Проверь друга»** | После ролла → отправить другу вызов. Друг кидает фото → его карта → **оба** в чате, кто кого смог | У друга лимит 3 ролла → покупает, чтобы не опозориться |
| **Батл по тегу** (`/mog @user`) | Публичный вызов в группе → весь чат смотрит | Крит-токены/роллы перед боем |
| **Лидерборд чата** | «Лучший ролл недели» в группе | Пин в топ, ролл-паки |
| **Share-карта** | PNG/видео с фольгой → в чат (законно: своё лицо) | Красивее карта → дороже скин |
| **«Второй шанс»** | После провала: «докупи ролл, отыграйся» | Импульсная покупка 15⭐ |
| **Сезон/ивенты** | Ивент-карты, серийные номера | Сезон-пасс |

**Легальность «проверь друга»:** друг проходит проверку **сам** (открыл, кинул своё фото → согласие).
Только **consensual** — снимает Apple 1.2 и нормы. Не оцениваем тех, кто не участвовал.

## 11. Порядок реализации (сам, деплой на Render)

1. `game/*` + `webapp/*` + проводка в `bot.py`.
2. Локальный прогон: `py_compile` + запуск сервера + `curl /app`, `/api/me`.
3. Деплой на Render (webhook-режим) → тест в Telegram.
4. Фаза 2: Stars-инвойсы, гифтинг, rewarded ads, сезоны.
